# v0.3.2

- You can export the photographs that are currently picked to a folder you choose. Each original is copied together with any existing XMP sidecar. Same-named files are not overwritten, and originals are not changed. When the export finishes, the app shows how many files succeeded or failed, and you can open the folder.
- In the album list, you can select several photographs and set a star rating, or a picked or rejected flag, for the selection at once. A click still opens the detail page. Command-click adds or removes a photograph, Shift-click selects a range, and Select All is also available. Partial failures show success and failure counts and reasons; successful saves are kept. Photographs that already have the target rating or flag are left unchanged.
- After an import finishes, the current session keeps a list of files that failed. You can retry only those failures, not files that already succeeded. A retry starts that file over and does not resume mid-file. Partial retry failures show success and failure counts and reasons, and successful retries are removed from the list.
- This release is for Apple silicon Macs running macOS 14 or later. The app uses a personal signature and is not notarized by Apple. Original photographs are still only read, never changed. Go by the interface you see in your own window, and by the import, export, and marking results you actually see with your own camera and files.
