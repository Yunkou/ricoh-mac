# v0.3.1

- The album list now uses 3:2 thumbnails, closer to the photograph's frame. Filters are no longer a row of equal-weight choices: picked, rejected, and the other flags form one group, and ratings live in a menu. In a narrower window, those options collapse into a single filter menu.
- Star ratings stay visible under the file name and can be clicked directly. Picked and rejected sit in the top-right corner of the thumbnail, and the format (for example JPEG or DNG) sits in the top-left corner. The existing keyboard shortcuts still work for these actions.
- The detail page gives more of the window to the photograph. The tool strip under the canvas groups previous and next, stars and flags, and Fit, Info, and Shortcuts. The full shortcut list is still available, but it is no longer a persistent hint line.
- In a wider window, photographer information appears on the right by default. In a narrower window it stays closed until you need it, and then opens as an overlay so it does not shrink the photograph. Press I to show or hide the information.
- This release is for Apple silicon Macs running macOS 14 or later. The app uses a personal signature and is not notarized by Apple. Original photographs are still only read, never changed. The detail page, RAW develop previews, star ratings, flags, and camera connection were already available. Go by the layout you see in your own window, and by the connection state you actually see with your own camera and files.
