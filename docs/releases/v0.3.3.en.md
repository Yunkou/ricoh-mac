# v0.3.3

- Adds a purpose description for macOS Local Network access. When joining the camera network times out or the camera does not respond after joining, connection messages explain where to check Local Network permission.
- Adds a first-connection guide and troubleshooting table, covering the camera network, system permissions, and the prompts to expect along the way. The README links to the guide.
- Adds a privacy statement explaining how photographs, previews, Location access, Keychain passwords, and local files are handled. New bug-report and feature-request forms help structure reports.
- Release pages use the bilingual changes written for each version, followed by installation steps, a download link, and a checksum to help identify and verify the download.
- This personal-use release targets Apple silicon Macs and declares macOS 14 as its minimum. It is ad hoc signed, not notarized by Apple, and not signed with a Developer ID; macOS may block the first launch. The permission messages do not imply completed validation across macOS versions or with a real camera.
