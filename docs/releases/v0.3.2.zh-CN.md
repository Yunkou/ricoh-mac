# v0.3.2

- 可以把当前已选的照片导出到指定文件夹。原片和已有的 XMP sidecar 一并复制，不会覆盖同名文件，也不会改写原片。完成后会显示成功和失败数量，并可以打开目标文件夹。
- 在相册列表中可以选中多张照片，批量设定星级或已选、排除标记。单击仍打开详情。Command-点击加选或减选，Shift-点击选择范围，也可以使用「全选」。部分失败时显示成功与失败数量及原因，已成功的保持已保存。已是目标星级或标记的照片不改写。
- 导入结束后，当前会话会保留失败文件列表。可以只重试这些失败项，不会再次导入已成功的文件。重试从该文件重新开始，不做文件中途续传。部分失败时显示成功与失败数量及原因，已成功的从列表中移除。
- 本版本适用于搭载 Apple 芯片、并运行 macOS 14 或更高版本的 Mac。应用使用个人签名，未经 Apple 公证。应用仍然只读取原片，不会修改它们。请以你在自己窗口里看到的界面，以及在自己的相机和文件上实际看到的导入、导出和标记结果为准。
