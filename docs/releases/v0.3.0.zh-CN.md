# v0.3.0

- 在「照片」中打开一张照片，会进入完整的详情页。你可以切换上一张和下一张，在适应窗口与显示像素之间切换，并查看拍摄信息，包括曝光、镜头与裁切、图像设定、对焦和直方图。按 I 可显示或隐藏信息面板。
- 若 DNG 含有嵌入预览，相册网格会显示缩略图。详情页还可以从 RAW 数据显影预览，并标明当前看到的是 RAW 显影还是嵌入预览。显影结果用于屏幕查看，经过缩小，并不是原片的 100% 像素。
- 你可以为照片打 1 到 5 星，或标记为已选、排除，也可以按星级或标记筛选相册。标记保存在照片旁边，不会改写原片。
- 打星或更改标记时，界面会提示正在保存或已经保存。删除已保存的相机网络前会要求确认。若筛选后仍留下当前这张不符合条件的照片，页面会明确标出。查看 RAW 显影或嵌入预览时，控件称为「显示尺寸」，以免和原片像素混淆。
- 本版本适用于搭载 Apple 芯片、并运行 macOS 14 或更高版本的 Mac。应用使用个人签名，未经 Apple 公证。应用仍然只读取原片，不会修改它们。连接相机和导入照片的能力此前已经提供；以你在自己的相机和文件上实际看到的连接状态与拍摄信息为准。
