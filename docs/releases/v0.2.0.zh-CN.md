# v0.2.0

- 启动后先进入两个入口：「照片」在左，「设备」在右。点整张卡片即可打开。
- 「设备」用于连接已保存的相机，浏览、选择并导入照片。导入完成后，可以直接查看已导入的照片。
- 「照片」用于浏览已经导入到本机的照片，不必连接相机。应用只读取这些文件，不会修改原片。
- 点开一张照片后，可以查看大图，用方向键或按钮切换上一张和下一张，也可以用快捷键缩放、查看信息或打开快捷键说明。
- 窗口去掉了软件名称和深色顶栏，红黄绿按钮直接叠在内容上。整个窗口使用系统深色毛玻璃效果。
- 界面文案改为更短的产品用语，不再显示路径、网络接口或报错细节这类技术说明。
- 图标改为 Kubai 官方多色版本。琥珀色按钮上的图标仍使用深色单色版本，以保证对比度。
- 应用内嵌 ChillDINGothic 字体，离线也可使用。该项始于 v0.1.1。
