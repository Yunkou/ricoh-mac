# v0.3.1

- 相册列表改用更接近照片画幅的 3:2 缩略图。筛选不再铺成一排同等权重的选项：「已选」「排除」等标记作为一组，星级收在菜单里；窗口较窄时，这些选项会收进一个筛选菜单。
- 星级始终显示在文件名下方，可以直接点按。「已选」和「排除」放在缩略图右上角，格式（例如 JPEG、DNG）显示在左上角。这些操作也可以用原来的键盘快捷键完成。
- 详情页把更多空间留给照片。底部工具条把上一张和下一张、星级与标记、以及适应窗口、信息和快捷键分成清晰的组别。完整快捷键列表仍可打开，但不再常驻一行提示。
- 较宽的窗口里，拍摄信息默认出现在右侧；较窄时默认收起，需要时以浮层打开，避免挤占照片。按 I 仍可显示或隐藏信息。
- 本版本适用于搭载 Apple 芯片、并运行 macOS 14 或更高版本的 Mac。应用使用个人签名，未经 Apple 公证。应用仍然只读取原片，不会修改它们。详情页、RAW 显影预览、星级标记和相机连接等能力此前已经提供。请以你在自己窗口里看到的布局，以及在自己的相机和文件上实际看到的连接状态为准。
