# 首次连接相机

这份指南写给第一次把 Ricoh Mac 连到相机的人。连接经过若干步系统授权和网络切换，任何一步失败，界面大多只显示「无法连接」。下面按顺序说明每一步该看到什么，再给出症状与处理的对照表。

英文版见 [first-connection.en.md](first-connection.en.md)。

## 开始前

- 相机已开机，并且**已在相机上打开无线网络**。GR IIIx 的操作见相机说明书里的无线局域网一节。
- 相机的电量和存储卡状态正常。
- 这台 Mac 没有把相机网络排除在外的代理或 VPN。若开着代理，请先按后面的对照表处理。

## 第一步：打开「设备」，点「连接相机」

进入「设备」，点「连接相机」。应用会先探测相机是否已经可达。

- **如果 Mac 已经在相机网络上**：直接进入第二步。
- **如果还没加入**：应用会请你保存相机网络。

## 第二步：保存相机网络

应用会请你输入相机屏幕上的**网络名称**和**密码**。

- 若应用检测到某个网络名称看起来就是相机网络，可能只让你输入密码。
- 第一次保存时，macOS 可能会问是否允许应用访问钥匙串。允许后，密码写入系统钥匙串。

密码不会写进应用的数据文件。

## 第三步：系统权限

连接过程中，系统可能询问两类权限。两者都会影响能否连上：

**定位权限**：macOS 只允许有定位权限的应用读取当前 Wi-Fi 名称。

- 允许：应用自动填入当前网络名称。
- 拒绝：仍然可用，但需要你手动输入相机屏幕上的网络名称。应用不使用、也不记录你的地理位置。

**本地网络权限**（macOS 15 起）：连接相机属于访问本地网络。

- 允许：应用可以访问相机地址 `http://192.168.0.1`。
- 拒绝：连接会被系统静默丢弃——不弹窗、设置里可能没有条目，界面只会显示连不上。可在 系统设置 → 隐私与安全性 → 本地网络 中允许本应用。

## 第四步：自动切换网络

保存过配置后，点「连接相机」会自动切换到相机网络。

- 切换过程中界面显示「正在加入网络…」。
- 成功后会探测相机，界面显示「已连接」，随后列出相机里的照片。
- 导入完成后，默认会切回你原来的网络。这个行为可以在设置里关闭。

## 第五步：导入

在照片列表中选择照片，然后「导入已选」或「全部导入」。照片按原文件名导入到你设置的保存位置。

导入结束后可以「查看照片」打开本地相册。当前会话里失败的项可以单独重试。

## 症状对照表

| 界面所示 | 常见原因 | 处理 |
| --- | --- | --- |
| 「无法连接」，且刚拒绝过系统弹窗 | 本地网络权限被拒绝（macOS 15+），连接被静默丢弃 | 系统设置 → 隐私与安全性 → 本地网络，允许本应用后再点「连接相机」 |
| 「没有读取当前网络名称的权限」 | 定位权限被拒绝 | 在 系统设置 → 隐私与安全性 → 定位服务 中允许；或手动输入相机屏幕上的网络名称 |
| 「无法加入相机网络，密码可能不正确」 | 相机屏幕上现在显示的密码与保存的不一致（相机每次开无线可能换密码） | 在设置里更新密码后重试 |
| 「等待相机网络超时」 | 相机无线未打开，或相机远离、信号弱；也可能是本地网络权限被拒 | 先在相机上打开无线网络并靠近相机；仍不行则检查本地网络权限 |
| 「已加入相机网络，但相机没有响应」 | 已切到相机网络，但相机地址不可达：相机休眠、代理占用、或本地网络权限被拒 | 唤醒相机确认无线仍开；检查本地网络权限；若开了代理，把相机网络排除出代理 |
| 「网络似乎被代理占用，相机可能连不上」 | 到 `192.168.0.1` 的路由经过隧道接口 | 把相机网络排除出代理后重试 |
| 「找不到本机的无线网络」 | 这台 Mac 没有可用的 Wi-Fi 接口（例如仅有有线） | 使用带 Wi-Fi 的 Mac，或改用以太网连到相机网络（视相机是否支持） |
| 「已保存过这台相机，但找不到密码」 | 钥匙串中的密码条目丢失或被移除 | 重新输入密码并保存 |
| 能连接，但导入中途失败 | 信号弱或传输中断 | 靠近相机重试；当前会话里可单独重试失败项 |
| 导入后仍停留在相机网络 | 自动切回被关闭，或切回失败 | 设置里开启「导入完成后自动切回原来的网络」，或用「切回原来的网络」按钮 |

## 仍然连不上

若上表都试过仍失败，请在提 issue 时附上：应用版本、macOS 版本、Mac 芯片、相机型号与固件、电脑是如何加入相机网络的、以及是否有代理或 VPN（见 [缺陷报告模板](../.github/ISSUE_TEMPLATE/bug_report.yml) 的字段）。
