# 相册列表与详情页布局

本文记录「照片」列表与详情页的布局方案。视觉世界仍遵循 `DESIGN.zh-CN.md`：固定深色、暖琥珀、透明毛玻璃、打包的 ChillDINGothic 与 Kubai 多色图标。这是在既有产品身份内调整结构，不是换一套外观。

## 任务与模式

用户在本机相册里浏览和选片：看照片、打开一张、打星或标记、继续下一张。这是 Operate 界面，同时必须让照片本身成为第一阅读对象。设备连接、导入、选中相机缩略图的业务不受本方案改动。

成功标准是：在列表和详情里，照片区域明显大于控件；筛选、密度和卡片信息有主次；星级、已选、排除既可用指针直接点到，也保留现有键盘操作；窄窗口有明确结构策略，而不是无限换行。

## 比较过的方向

1. **沉浸式画布。** 详情几乎铺满照片，控件以自动隐藏的浮层出现；列表做成更密的接触印样，标记只留小徽章。优点是图像最大。缺点是关键操作容易变成悬停才能发现，也不符合选片工具应随时可见的操作习惯。
2. **选片工作台（采用）。** 列表用一条低权重工具行管理筛选；卡片以 3:2 照片为主，文件名、格式、星级和标记分层放置且始终可点。详情用大画布加可收起的拍摄信息，导航、选片和查看控件收成一组有结构的工具条。优点是照片优先，同时保持选片效率。缺点是详情工具条在很窄的窗口仍需分成两行。
3. **信息优先。** 常驻较宽的元数据栏，照片缩小。与「照片为主」相反，只作为对照，不采用。

采用方向 2。它把浏览和选片当作同一条工作路径，又不引入应用侧栏、产品大标题或新的路由。

## 空间原则

- 主路径：看见照片 → 打开或标记 → 下一张。
- 列表里，缩略图领先；文件夹路径与数量、筛选、网格本身分属不同层级，不把十个芯片和每格一排按钮做成同等权重。
- 详情里，当前显示图像领先；拍摄信息是可收起的辅助；导航和标记是支持，不是与照片争位置的第三块画布。
- 节奏：控件组内部用紧间距（4–8 点），组与组、照片与工具条之间用更宽的间隔。
- 适配按窗口宽度切换结构，不按设备型号判断。

## 列表

顶栏仍是透明拖动区：返回、照片 / 设备切换、资料库路径、数量和刷新。不增加常驻侧栏，也不加产品标题。

筛选行：

- 宽度不小于 720 点时，「全部 / 已选 / 排除 / 无标记」作为一组；「星级」是单独的菜单按钮，打开后选择未评级或 1–5 星。选中星级后，按钮显示当前条件。
- 宽度小于 720 点时，合并为一个「筛选 · 当前条件」菜单，内含上述全部选项。
- 筛选语义不变：标记和星级仍是单选，不能叠加。

卡片：

- 缩略图为 3:2，覆盖裁切，比正方形更接近 GR 默认画幅。
- 左上角是格式徽章（JPEG / DNG 等），右上角是始终可见的「已选」「排除」，点击区保持至少 24 CSS 像素。
- 文件名在缩略图下方一行，中间省略。
- 五枚星标在文件名下方，始终可见，点击区至少 24 CSS 像素，相邻至少 4 点。
- 键盘快捷键 0–5、P、X、U 保持不变，不把关键功能改成仅悬停出现。
- DNG 仍使用内嵌预览；无法预览时保留占位说明；不符合筛选但仍保留的照片继续标明「不符合当前筛选」。

「设备」网格仍使用正方形缩略图加 22 点文件名，不把相册的选片控件带过去。

## 详情页

详情仍是与相册网格平级的独立页面，不是弹窗。顶栏的返回、文件名和区域切换位置不变，也不侵入红绿灯拖动区。Space / Enter 打开、Escape 返回并恢复位置与焦点、I 切换信息、F 切换适应窗口或显示像素、Shift-/ 打开快捷键列表，这些行为保持不变。

画布占据返回栏与工具条之间的全部剩余空间。来源说明和 RAW / 嵌入预览切换仍叠加在画布上。

拍摄信息：

- 宽度达到 900 点时，默认在右侧栏打开。
- 更窄时默认关闭；打开后使用浮层，而不是再切出一列把画布压窄。
- 「照片尺寸」与「显示尺寸」的区分，以及「原片 1:1」只用于 JPEG 原片、RAW 显影或嵌入预览使用「显示尺寸」的语义，不得退回。

工具条分三组：上一张 / 片序 / 下一张；星级与标记；适应窗口、信息、快捷键。宽度达到 900 点时三组同一行；在 720 到 900 点之间以及更窄时，分为两行（导航与选片在上，查看控件在下）。不再常驻一行快捷键提示，完整列表仍可由控件或 Shift-/ 打开。

## 窗口宽度

| 宽度 | 列表 | 详情 |
| --- | --- | --- |
| ≥ 900 点 | 标记分段 + 星级菜单；3:2 多列网格 | 信息侧栏默认打开；工具条一行 |
| 720–899 点 | 同上，列数随宽度减少 | 信息默认关闭，打开则为浮层；工具条两行 |
| < 720 点 | 单一筛选菜单；一列或两列 | 同上，工具条两行 |

## 未改动的范围

不改设备连接、导入、相机选中逻辑，不新增选片功能或复杂路由，不更换主题、字体或图标系统，不把 Impeccable 技能或快照纳入产品说明。

## 仍需在真实窗口目视的事项

无头测试可以覆盖筛选菜单、格式徽章、始终可见的星级与标记、详情返回与快捷键、信息显隐和来源切换，以及 720 / 900 的结构规则。以下仍需在本机 `nsh dev` 的真实窗口里查看，不能仅凭源码宣称通过：

- 3:2 缩略图裁切是否合适，文件名省略和徽章对比是否清楚
- 缩略图上的已选 / 排除在浅色或复杂画面上是否仍然可读、是否达到 24 像素点击区
- 720 与 900 以及更窄时，筛选菜单、详情浮层和两行工具条是否拥挤或遮挡
- 毛玻璃、顶栏拖动区和红绿灯是否仍然干净
- 从详情返回后，网格滚动位置与焦点是否在观感上正确
