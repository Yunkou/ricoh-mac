These SVG files were retrieved from the official color API, which is
documented at https://icons.kubai.design/docs/static/, and pinned to
package version 0.9.0. The official library has two variants, color and
soft. Color is the default multi-tone style: gradients, outlines, marks,
and shadows are all derived from one accent color. Soft is the muted
variant. Interface icons use the color variant at size 96, with accents
taken from ui/theme.ts (amber, neutrals, and semantic success, warning,
and danger). Primary-button icons (*-on-accent.svg) stay on the soft
variant in the on-accent near-black, so they remain monochrome and
legible on the amber fill. The app vendors the files and does not load
icons from the network at runtime.
