## Install

This build is an ad hoc signed macOS application. It is not notarized and it is not signed with a Developer ID. Gatekeeper may block the first launch.

- Unzip the archive, then right-click `ricoh-mac.app` and choose Open.
- Or remove the quarantine attribute:

```sh
xattr -dr com.apple.quarantine ricoh-mac.app
```


## 安装

此构建为 ad hoc 签名的 macOS 应用，未经公证，也未使用 Developer ID 签名。系统可能会在首次打开时拦截。

- 解压后，按住 Control 点按（或右键点按）`ricoh-mac.app`，再选择「打开」。
- 或者移除隔离属性：

```sh
xattr -dr com.apple.quarantine ricoh-mac.app
```
